# Greeting Machine

This is a beginner program that interacts with the user by asking for their name and age. It demonstrates basic concepts like:

- Printing messages
- Taking user input
- Working with strings
- Using variables
- Converting data types
- Using conditional logic

## What the program does

1. Greets the user.
2. Asks for their name.
3. Says hello and tells them the length of their name.
4. Asks for their age.
5. Calculates and tells them how old they will be in 5 years, using proper grammar (year/years).

## How to run it

```bash
python greeting_machine.py

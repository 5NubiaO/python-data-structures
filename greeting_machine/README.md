#Greeting machine

This is a begginer program that interacts with the user by asking their name and age. It demonstrate basic concepts like:
-Printing messages
-Taking user input
-Working with strings
-Using variables
-Conerting data types
-Usingn conditional loic

##What the program does
1. Greets the user.
2. Asks for their name.
3. Says hello and tells them the length of their name.
4. Asks for their age.
5. Calculates and tells them how old they will be in 5 years, using proper grammar (year/years).
